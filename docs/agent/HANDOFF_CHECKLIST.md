# Agent handoff checklist

Before handing work to another Codex task or agent, record:

- exact repository, branch, and dirty files;
- milestone and acceptance criterion being pursued;
- commands already run and their results;
- changed public contracts and compatibility impact;
- unresolved risks or user decisions;
- the next smallest verifiable action.

Do not paste credentials, private addresses, full environment dumps, or private
deployment logs. Prefer a correlation ID and the redacted output of
`pfremote context` or `pfremote doctor`.
